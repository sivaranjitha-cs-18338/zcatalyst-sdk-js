generateAuthToken

  • generateAuthToken(feature): Promise<{
        access_token: string;
        expires_in_sec: number;
    }>

  • Generates an OAuth access token for the currently authenticated browser user, scoped to the given feature.

    Internally, a short-lived custom JWT is requested from Catalyst and then exchanged for an OAuth access token via the IAM remote-auth endpoint.

    Parameters

    • feature: "functions" | "stratus"

      The feature the generated token should be scoped for.

    Returns Promise<{
        access_token: string;
        expires_in_sec: number;
    }>

    A promise that resolves to the OAuth access token and its expiry (in seconds).

    Throws

    when feature is invalid, the custom token cannot be fetched, or the JWT-to-OAuth token exchange fails.

    Example

    const { access_token, expires_in_sec } = await zcAuth.generateAuthToken('functions');

signIn

  • signIn(id, config?): Promise<void>

  • Starts the embedded IAM sign-in flow inside a target DOM element or redirects an already authenticated user.

    Parameters

    • id: string

      DOM element ID where the login iframe should be mounted.

    • config: ICatalystSignInConfig = {}

      Sign-in configuration.

      • redirectUrl: URL to open after successful sign-in.
      • serviceUrl: Service URL used as the post-login destination.
      • cssUrl: Custom CSS URL for the sign-in page.
      • signInProvidersOnly: Whether to show only configured federated sign-in providers.
      • forgotPasswordId: DOM element ID where the forgot-password iframe should be mounted.
      • forgotPasswordCssUrl: Custom CSS URL for the forgot-password page.

    Returns Promise<void>

    A promise that resolves after the sign-in iframe flow is prepared or a redirect is triggered.

    Throws

    when the target DOM element cannot be found.

    See

    zcAuth in ./node for the Node.js authentication surface.

    Example

    import { zcAuth } from '@zcatalyst/auth';

    await zcAuth.signIn('login-container', { redirectUrl: '/dashboard' });
